Privacy Policy

Last updated 2026. Signal Toolkit is a static, frontend-only site — this policy is short because there isn't much to say.

What we collect

Nothing. Any content you type or upload into a Signal tool — URLs, WiFi passwords, contact details, or image files — is processed entirely in your browser using JavaScript. It is never transmitted to a server, because this site has no server-side component or backend of any kind, for any tool.

Local storage

Some tools save history, favorites, or preferences using your browser's local storage, a feature built into every modern browser. This data stays on your device and is never uploaded anywhere. Clearing your browser data, or using a tool's built-in "Clear" option, removes it.

Images and files

Tools like the Image Compressor read files you select using your browser's File API and process them on your device's own processor. At no point is an image file, or any part of it, sent over the network.

Cookies

This site does not set tracking or advertising cookies.

Third-party fonts and libraries

Google Fonts, and small open-source JavaScript libraries loaded from a public CDN, are used to display typography and power certain tools. Loading these resources may expose your IP address to the hosting provider in the same way any external resource request does. No content you enter into a tool is sent alongside these requests.

Contact

Questions about this policy can be sent to hello@signal-qr.example.com.
