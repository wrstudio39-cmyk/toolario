FAQ

Common questions

How do I convert WebP to PNG?

Drop or select your WebP file above, confirm the output is set to PNG, and download the converted file — everything happens instantly in your browser.

Why convert WebP to PNG?

PNG is supported everywhere, including older design and editing software that doesn't yet recognize WebP files. This tool works best when you need to open or edit the image in software that doesn't support WebP.

Does this image compressor upload my photos anywhere?

No — every image is read and processed locally using your browser's Canvas API. Nothing is ever sent to a server.

What image formats can I convert between?

You can convert between JPG, PNG, and WebP, or keep the original format while only reducing quality and dimensions.

Will compressing lose image quality?

JPG and WebP use adjustable lossy compression, so quality depends on the slider. PNG output stays lossless, so only resizing changes its size.

Can I compress multiple images at once?

Yes — drop or select multiple files and Signal batch-processes all of them with the same settings, then lets you download them individually or as one ZIP.

Does this tool remove EXIF metadata?

Yes — because images are redrawn onto a canvas and re-encoded, EXIF metadata such as GPS location and camera details is stripped automatically.

What's the largest image size this can handle?

It depends on your device's memory, but most modern browsers comfortably handle images up to several thousand pixels wide. Very large batches may take a few seconds longer to process.

Can I use compressed images commercially?

Yes — compression and conversion don't add any licensing restriction. You retain whatever rights you already had over the original image.
